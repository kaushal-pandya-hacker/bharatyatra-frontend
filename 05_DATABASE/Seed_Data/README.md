# Seed Data Guidelines — Chalo Farva

## Seed Scripts Overview
- `seed_reference_data.sql`: Populates system roles, baseline permissions, payment providers, and system templates.
- `seed_gujarat_destinations.sql`: Populates 24 verified Gujarat destinations with coordinates, regions, and descriptions.

All seed data is strictly reference data for development and initial staging deployments. Demo inventory is clearly prefixed with `DEMO_`.
