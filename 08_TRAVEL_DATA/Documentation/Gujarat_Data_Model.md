# Gujarat Data Model Specification — Chalo Farva

## Core Entities
- **Destination**: Primary geographical cluster (Ahmedabad, Somnath, Statue of Unity, Rann of Kutch, Gir, etc.).
- **Attraction**: Sights, stepwells, monuments within destinations.
- **Temple / Religious Place**: Darshan timings, dress code restrictions, festival relevance.
- **Wildlife Sanctuary**: Safari seasonality, forest department permits, species.
- **Beach**: Blue flag certification, coastal wind/wave sensitivity.
- **Heritage Site**: UNESCO designations, Solanki/Sultanate historical periods.
- **Route**: Inter-city road travel corridors (distance, typical duration, transport mode).
