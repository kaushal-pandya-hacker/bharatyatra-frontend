# AI Data Usage Rules — Chalo Farva

## Strict AI Usage Rules
1. **Never Invent Facts**: If a fact is unknown or stale, the AI engine MUST reply with "Information unverified" or mark as `UNKNOWN` rather than hallucinating opening hours or prices.
2. **Provenance Badging**: Every AI prompt response that includes facts retrieved from the knowledge base must attach provenance metadata (`[Verified Data]`, `[Live Availability]`).
3. **No Uncontrolled Actions**: AI Engine cannot charge payments or modify bookings without explicit user confirmation.
