# Notification Architecture — Chalo Farva

## Multi-Channel Messaging
- **WhatsApp API Integration**: Booking confirmations, e-tickets, weather advisories.
- **SMS Gateways**: OTP authentication & emergency trip alerts.
- **Email (SMTP/SendGrid)**: Detailed invoices, PDF booking receipts, itinerary summaries.
- **In-App Push**: Real-time adaptive re-routing suggestions.
