# Admin Analytics Dashboard Specification v1.1 — Chalo Farva

**Target System**: Admin Panel (`18_DEVELOPMENT/Frontend/app/admin/analytics/`)  

---

## Dashboard Tab Layout & Components

1. **Overview Tab**: Macro KPI cards (Registrations, Search Volume, AI Plans, Bookings Confirmed, Authoritative Revenue, Net Margin).
2. **Funnel Tab**: 13-Stage conversion funnel visualization with drop-off percentages between consecutive steps (`Visitor` → `Destination` → `Search` → `AI Planner` → `Itinerary` → `Checkout` → `Payment` → `Booking` → `Trip`).
3. **AI & Adaptive AI Tab**: Prompt acceptance rate (72.0%), average generation latency (1,420ms), model/prompt version metrics, Adaptive AI trigger approval rate (88.7%).
4. **Bookings & Payments Tab**: Payment success rate (99.4%), booking success rate (99.1%), 4-way reconciliation status, cancellation rate.
5. **Suppliers Tab**: Real-time supplier quality scorecards, top-rated vs underperforming vendor counts.
6. **Revenue & Contribution Margin Tab**: GBV (₹14.25M), Commission (₹855K), Fees (₹285K), Gateway cost (₹199.5K), Supplier Payable (₹12.91M), Net Contribution Margin (6.6%).
