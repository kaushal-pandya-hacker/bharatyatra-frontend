# Accessibility Test Report v1.0 — Chalo Farva

**Audit Domain**: WCAG 2.1 Level AA Compliance & Screen Reader Usability  

---

## Accessibility Audit Summary

- **Keyboard Navigation**: All interactive buttons, inputs, modals, and search cards are navigable via `Tab` and `Shift+Tab`.
- **Focus States**: Visible high-contrast focus rings active across Next.js UI primitives.
- **Color Contrast**: Text elements satisfy 4.5:1 minimum contrast ratio against dark & glass backgrounds.
- **ARIA Landmarks & Labels**: Semantic HTML5 tags (`<nav>`, `<main>`, `<section>`) and `aria-label` tags present on interactive CTA buttons.
