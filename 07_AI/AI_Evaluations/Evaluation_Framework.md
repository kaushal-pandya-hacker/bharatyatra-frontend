# AI Planner Evaluation Framework v1.0

## Evaluation Metrics
1. **Schema Compliance Rate (Target: 100%)**: Valid JSON conforming to Pydantic schema.
2. **Hard Constraint Violation Rate (Target: 0%)**: Zero violations of monsoon closures or Monday maintenance rules.
3. **Budget Accuracy Rate (Target: >= 98%)**: Total estimated cost within budget cap.
4. **Geographic Efficiency (Target: >= 90%)**: Zero geographic backtracking.
5. **Provenance Grounding Score (Target: >= 85%)**: Percentage of recommended POIs grounded in verified facts.
