# CARD COMPONENTS SPECIFICATION — CHALO FARVA

- **Destination Card**: Aspect ratio 4:3 image, region badge top-left, title, recommended stay duration, "Plan with AI" CTA button.
- **Hotel Search Card**: Image slider left (30%), hotel name, star rating, address, amenities icons, base price per night, `[Verified]` provenance tag.
- **Bus Schedule Card**: Operator logo, departure/arrival times, transit duration, bus type (AC Volvo), available seats badge, price per seat, "Select Seats" CTA.
