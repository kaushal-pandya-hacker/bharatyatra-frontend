# ADMIN SCREEN SPECIFICATIONS — CHALO FARVA

## Screen 1: Executive Dashboard (`/admin/dashboard`)
- **Metric Cards**: Total Active Travellers, Total Bookings, Gross Revenue, AI Adaptation Acceptance Rate.
- **Charts**: 30-day booking volume area chart, revenue distribution pie chart by category (Hotels vs Buses vs Packages).
- **Action Feed**: Pending supplier verifications, refund approval queue, open high-priority support tickets.

## Screen 2: AI & Adaptive Monitor (`/admin/ai-monitoring`)
- **Real-Time Log Table**: Log ID, Trip ID, Event Trigger (e.g. Monsoon Alert in Somnath), AI Proposed Substitution, Confidence Score, User Action (Accepted/Rejected).
- **Override Controls**: Ability for admin to pause specific AI adaptation rules during system maintenance.
