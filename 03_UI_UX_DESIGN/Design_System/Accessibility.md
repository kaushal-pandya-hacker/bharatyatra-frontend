# ACCESSIBILITY (WCAG 2.1 AA) SPECIFICATION — CHALO FARVA

1. **Color Contrast**: All primary text maintains a minimum contrast ratio of 4.5:1 against backgrounds (e.g. `#0F172A` on `#FFFFFF` = 16.1:1).
2. **Focus Rings**: Keyboard navigation shows a high-visibility focus ring `2px solid #FF6B35` with `2px offset`.
3. **Screen Readers**: All interactive elements include explicit `aria-label` or `aria-labelledby` attributes.
4. **Color Independence**: Status information (Confirmed, Pending, Failed) uses distinct icons in addition to color indicators.
