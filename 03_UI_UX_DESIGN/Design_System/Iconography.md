# ICONOGRAPHY SYSTEM — CHALO FARVA

## Standards
- **Icon Library**: Lucide Icons / Heroicons (Outline style by default).
- **Stroke Width**: 1.75px for standard icons, 2px for small 16px icons.
- **Sizes**: `sm: 16px`, `md: 20px`, `lg: 24px`, `xl: 32px`.
- **Primary Travel Icons**: Compass (Discover), MapPin (Destinations), Calendar (Itinerary), Bus (Transit), Hotel (Stay), Sparkles (AI Planner), ShieldCheck (Verified Data).
