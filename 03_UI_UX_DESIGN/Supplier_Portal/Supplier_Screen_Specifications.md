# SUPPLIER SCREEN SPECIFICATIONS — CHALO FARVA

## Screen 1: Vendor Dashboard (`/supplier/dashboard`)
- **Key Metrics**: Today's Check-ins / Passengers, Available Inventory Count, Month-to-Date Earnings.
- **Recent Manifest**: Table of confirmed customer bookings with guest names, contact numbers, and check-in/departure times.

## Screen 2: Inventory Manager (`/supplier/inventory`)
- **Calendar Grid**: Interactive date grid showing daily available room counts or bus seat layouts.
- **Quick Bulk Edit**: Select date range $\rightarrow$ Adjust available count / block inventory for maintenance.
