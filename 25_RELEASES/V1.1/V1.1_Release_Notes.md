# Release Notes v1.1.0 — Chalo Farva

**Release Version**: v1.1.0  
**Release Date**: September 13, 2026  
**Scope**: Post-Launch Optimization, Analytics Taxonomy, Experimentation Engine & Supplier Scoring  

---

## What's New in v1.1.0

### 🚀 New Features & Modules
- **Backend Analytics Engine (`AnalyticsModule`)**: Added platform event taxonomy tracking across 30 distinct event types (`USER_REGISTERED`, `AI_PLANNER_STARTED`, `BOOKING_CONFIRMED`, `ADAPTATION_TRIGGERED`) and 10 admin telemetry REST APIs (`/api/v1/analytics/*`).
- **A/B Experimentation Framework (`ExperimentsModule`)**: Full A/B testing infrastructure supporting deterministic user variant assignment, guardrail monitoring, and decision tracking (`SHIP`, `ITERATE`, `ROLLBACK`, `STOP`).
- **Supplier Scorecard Engine**: Integrated real-time supplier quality calculation (50% booking success, 30% low-complaint score, 20% user rating) for partner payouts and ranking.

### 🛡️ Safety & Reliability Hardening
- **Adaptive AI Safety Hierarchy**: Enforced zero autonomous paid charges rule. All paid trip adaptations require explicit user authorization.
- **Provider Fallback Routing**: Added retry backoff for bus and hotel booking confirm calls to eliminate payment-after-booking discrepancies.

### 📊 Public Launch & Governance
- **11-Point Expansion Gate Scorecard**: Operationalized non-Gujarat market expansion evaluation pipeline.
- **Pytest Suite**: Expanded test suite to **45 passing test cases**.
